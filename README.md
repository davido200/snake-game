# Snake 🐍

A modern Snake game built with vanilla HTML, CSS, and JavaScript. Play directly in your browser — no install needed.

**Play now:** https://davido200.github.io/snake-game/

## Features

- **Smooth gameplay** — `requestAnimationFrame`-powered loop with configurable tick rate
- **Keyboard controls** — Arrow keys or WASD to move, P/Esc to pause
- **Touch controls** — Swipe anywhere on the board to change direction on mobile
- **Pause & Resume** — Pause anytime and pick up where you left off
- **Difficulty levels** — Easy, Normal, and Hard with different speeds
- **Score tracking** — Current score + persistent high score (saved in localStorage)
- **Clean UI** — Dark theme, subtle grid, animated food, snake with eyes
- **Responsive** — Works on desktop and mobile screens

## How to Play

1. Open the game in a browser
2. Use arrow keys or WASD (or swipe on mobile) to steer the snake
3. Eat the yellow food to grow and earn points
4. Avoid hitting walls or your own tail
5. Press **P** or **Esc** to pause, **R** to restart after game over

## Controls

| Input | Action |
|-------|--------|
| Arrow keys / WASD | Move the snake |
| P / Esc | Pause / Resume |
| R | Restart (after game over) |
| Swipe (mobile) | Change direction |

## Difficulty

- **Easy** — Slower speed, more time to react
- **Normal** — Balanced default speed
- **Hard** — Fast pace, quick turns required

## Tech

- Single-file HTML5 game — just open `index.html` in a browser
- No dependencies, no build step
- All logic in vanilla JavaScript
